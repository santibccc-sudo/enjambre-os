# Start here

Every markdown file in this folder becomes a node in the memory graph, and every
`[[link]]` becomes an edge. Write down [[conventions]], [[decisions]] and the
[[incidents]] that taught you something. Agents can search this memory through the
API and the `memory_query` MCP tool.
