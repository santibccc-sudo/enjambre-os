# enjambre

*Enjambre* is Spanish for swarm. It turns agents that already exist (a CLI coder, a
local model, a hosted API) into one system with a [[kernel]], a [[policy]] everyone
obeys, a [[router]] that picks who works, and this [[memory-graph]].

It grew out of a real swarm running on a solar-powered workstation and a small cloud
server. Every rule in it was paid for by an incident: see [[incidents]].
