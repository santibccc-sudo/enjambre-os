# genome

`swarm.yaml` declares agents, router, scheduler and kernel settings. `policy.yaml`
holds the [[policy]]. `prompts/` holds each agent's role. `memory/` is this graph.
Put the folder in git and every change to the swarm has an author, a date and a revert.
